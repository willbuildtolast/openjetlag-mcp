# Security

## Official endpoint

The only official OpenJetLag MCP endpoint will be listed in this repository's README. Forks and look-alike servers are not maintained by this project; only connect servers you trust.

## Design

- All tools are read-only, take no credentials and store nothing.
- Tool names, descriptions and server instructions are defined in source code and change only through reviewed commits, so changes are visible in the git history.
- Request bodies are capped at 64 KB.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's "Report a vulnerability" (Security tab) rather than in a public issue.
